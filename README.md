A first-person excuse from a tired little robot vacuum: cliff sensor,
bumper, and a battery that gave up two feet from the dock — with a clean
turn at the end, because the crumbs never stood a chance. The program is
pure-stdlib Python and writes that one line, deterministically, to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```
